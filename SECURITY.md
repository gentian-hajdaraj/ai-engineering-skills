# Security and trust boundaries

These skills are plain-text instructions for AI agents. They **cannot grant permissions on their own**, but agents that follow them may have access to files, tools or execution environments. **Always review tool permissions and keep human approval gates for destructive or publishing operations.**

Do not include credentials, customer data, proprietary code or unpublished internal findings in issues, pull requests or examples.

If you believe a repository file contains a secret or vulnerability, avoid disclosing it in a public issue. Contact the maintainer through the research contact on their [public profile](https://github.com/gentian-hajdaraj) or use GitHub's private vulnerability reporting option if enabled.

This repository is not a security product. It does not replace penetration testing, threat modeling, static analysis or runtime verification.
